# User Story Map（WhatsFeed）

按交付状态跟踪用户可见能力。变更能力或导航时，在同一 PR 更新本文件。产品概述见 [product README](./README.md)。

## Delivered

- 登录 / 注册与 JWT 会话
- Feed 信息流（帖子浏览与互动）
- Explore 探索网格
- 基础 IM / 通话入口（依当前实现）
- 管理后台基础能力

## In Progress

- Explore AI BFF（Nest 代理流式对话，与本地 Ollama 并存）
- Cursor 工程规范对齐（rules / skills / agents）

## Future

- Mobile 完整对齐 Explore AI
- RAG 能力经 Nest 产品化暴露
- Agents / Tools 产品入口

## 维护说明

| 状态 | 含义 |
|------|------|
| Delivered | 已在主线可用 |
| In Progress | 开发中或 Draft PR |
| Future | 已识别但未开工 |
