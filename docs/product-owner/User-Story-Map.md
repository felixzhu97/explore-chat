# 用户故事地图

按交付状态组织；每条仅保留用户故事（As a / I want / So that）。

## 已交付

### 认证与账号

**As a** 用户  
**I want** 安全注册与登录  
**So that** 我可以使用 WhatsFeed 的社交与通讯功能

### 即时通讯

**As a** 用户  
**I want** 发送与接收私信（含实时推送）  
**So that** 我可以与联系人即时沟通

### 信息流与帖子

**As a** 用户  
**I want** 浏览关注信息流并发布图文/视频帖  
**So that** 我可以分享与消费社交内容

### Reels 与探索

**As a** 用户  
**I want** 浏览短视频与探索网格  
**So that** 我可以发现新内容和创作者

### 评论与互动

**As a** 用户  
**I want** 对帖子点赞、收藏与评论  
**So that** 我可以与内容互动

### 关注关系

**As a** 用户  
**I want** 关注/取关其他用户并查看粉丝列表  
**So that** 我可以建立社交关系

### 音视频通话

**As a** 用户  
**I want** 发起 WebRTC 音视频通话  
**So that** 我可以进行实时语音或视频交流

### 管理后台

**As a** 管理员  
**I want** 管理用户与内容安全相关配置  
**So that** 我可以运营平台

### Explore AI（经 BFF）

**As a** 用户  
**I want** 通过 WhatsFeed 后端使用 Explore AI 能力  
**So that** 我无需也不应直接暴露上游 AI 服务凭证

## 进行中

### 生产部署

**As a** 开发者  
**I want** 将 Nest API 与托管 Postgres/Redis 部署到云平台  
**So that** 预发/生产环境可稳定访问

### 对象存储媒体

**As a** 用户  
**I want** 上传的媒体在重启后仍可访问  
**So that** 帖子媒体不因临时磁盘而丢失

## 未来

### 完整推荐与审核链路

**As a** 用户  
**I want** 更个性化的探索排序与可靠内容审核  
**So that** 发现体验更安全、更相关

### 离线与多设备同步

**As a** 移动端用户  
**I want** 弱网下可靠收发消息  
**So that** 通讯体验接近主流 IM
