# E1 认证与账号

← [用户故事地图](../User-Story-Map.md)

## 背景

用户需要安全注册与登录，才能使用 WhatsFeed 的社交与通讯功能。

---

## US-01 注册与登录

**As a** 终端用户  
**I want** 安全注册与登录  
**So that** 我可以使用 WhatsFeed 的社交与通讯功能

### 验收标准

1. **Scenario** 新用户完成注册并进入已登录状态
   **GIVEN** 用户未登录且打开注册流程  
   **WHEN** 用户提交有效注册信息  
   **THEN** 账号创建成功且用户处于已登录状态

2. **Scenario** 已有用户登录成功
   **GIVEN** 用户拥有有效账号  
   **WHEN** 用户提交正确凭证登录  
   **THEN** 用户进入已登录状态并可访问主功能
