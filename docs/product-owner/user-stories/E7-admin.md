# E7 管理后台

← [用户故事地图](../User-Story-Map.md)

## 背景

管理员需要运营用户与内容安全相关配置。

---

## US-10 管理后台

**As a** 管理员  
**I want** 管理用户与内容安全相关配置  
**So that** 我可以运营平台

### 验收标准

1. **Scenario** 管理员进入后台完成基础运营操作
   **GIVEN** 用户具备管理员权限并已登录  
   **WHEN** 用户打开管理后台  
   **THEN** 可访问用户或内容安全相关管理入口并完成允许的操作

已实现
