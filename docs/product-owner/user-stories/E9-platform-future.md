# E9 平台与未来

← [用户故事地图](../User-Story-Map.md)

## 背景

平台可靠性与媒体持久化、推荐审核、多设备同步等能力仍在进行或规划中。

---

## US-12 生产部署

**As a** 开发者  
**I want** 将 Nest API 与托管 Postgres/Redis 部署到云平台  
**So that** 预发/生产环境可稳定访问

### 验收标准

1. **Scenario** 生产拓扑可访问健康检查
   **GIVEN** API 已部署到目标平台且数据库与 Redis 已配置  
   **WHEN** 运维访问健康检查端点  
   **THEN** 返回健康状态且服务可对外提供 API

### 状态

进行中

---

## US-13 对象存储媒体

**As a** 终端用户  
**I want** 上传的媒体在重启后仍可访问  
**So that** 帖子媒体不因临时磁盘而丢失

### 验收标准

1. **Scenario** 重启后媒体 URL 仍可用
   **GIVEN** 用户已上传媒体并成功发帖  
   **WHEN** API 进程或实例重启  
   **THEN** 原媒体 URL 仍可访问（对象存储或等效持久化）

### 状态

进行中

---

## US-14 完整推荐与审核

**As a** 终端用户  
**I want** 更个性化的探索排序与可靠内容审核  
**So that** 发现体验更安全、更相关

### 验收标准

1. **Scenario** 探索排序与审核可感知
   **GIVEN** 推荐与审核链路已启用  
   **WHEN** 用户浏览探索或发帖  
   **THEN** 排序结果反映个性化/热度策略  
   **AND** 违规内容按策略被拦截或标记

### 状态

规划中

---

## US-15 离线与多设备同步

**As a** 移动端用户  
**I want** 弱网下可靠收发消息  
**So that** 通讯体验接近主流 IM

### 验收标准

1. **Scenario** 弱网恢复后消息可达
   **GIVEN** 用户曾短暂离线并发送或接收消息  
   **WHEN** 网络恢复  
   **THEN** 消息最终一致地出现在会话中

### 状态

规划中
