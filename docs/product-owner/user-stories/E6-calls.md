# E6 音视频通话

← [用户故事地图](../User-Story-Map.md)

## 背景

用户需要在应用内发起 WebRTC 音视频通话。

---

## US-09 音视频通话

**As a** 终端用户  
**I want** 发起 WebRTC 音视频通话  
**So that** 我可以进行实时语音或视频交流

### 验收标准

1. **Scenario** 发起通话信令可达
   **GIVEN** 双方已登录且网络可用  
   **WHEN** 用户向联系人发起通话  
   **THEN** 对方收到来电或信令提示  
   **AND** 接通后可建立媒体会话（依赖 TURN/STUN 可达）

### 状态

已实现
