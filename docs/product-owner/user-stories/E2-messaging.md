# E2 即时通讯

← [用户故事地图](../User-Story-Map.md)

## 背景

用户需要与联系人实时收发私信，保持沟通连续性。

---

## US-02 实时私信

**As a** 终端用户  
**I want** 发送与接收私信（含实时推送）  
**So that** 我可以与联系人即时沟通

### 验收标准

1. **Scenario** 发送消息后对方可实时看到
   **GIVEN** 双方均已登录且存在会话  
   **WHEN** 用户发送一条文本消息  
   **THEN** 消息出现在会话中  
   **AND** 接收方可在无需整页刷新的情况下看到新消息

2. **Scenario** 会话列表可定位历史对话
   **GIVEN** 用户已有多个会话  
   **WHEN** 用户打开消息入口  
   **THEN** 可看到会话列表并进入目标会话
