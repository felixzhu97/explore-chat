# Contributing

Thanks for your interest in Explore Chat.

## Development

Requires Node.js ≥ 18, [pnpm](https://pnpm.io/) ≥ 10, and the setup described
in the project README.

```bash
pnpm install
pnpm setup
```

Useful checks:

```bash
pnpm check-types
pnpm lint
```

## Pull requests

1. Branch from `main` using a single English kebab-case slug.
2. Keep changes focused; keep Glossary terms and C4 docs in sync when
   packages or APIs change.
3. Ensure `pnpm check-types` and `pnpm lint` pass before opening a PR.
4. Open a PR against `main` with a clear why and References.
